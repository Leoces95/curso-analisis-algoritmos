# REPOSITORIO PARA EL CURSO ANALISIS DE ALGORITMOS

Este repositorio almacena las actividades del curso Análisis de Algoritmos.

## ESTRUCTURACIÓN DE CARPETAS

* **`laboratorios/`**: Contiene cinco informes de laboratorios evaluativos.
* **`ejercicios-clase/`**: Código de las sesiones prácticas no evaluativas, incluyendo los ejercicios de Python de la Semana 2.
* **`benchmarks/`**: Scripts compartidos de medición de tiempos y graficación.

## INSTRUCCIONES DE USO

Dado que es el inicio del curso, las instrucciones de uso del repositorio se remiten de momento a la clonación del proyecto:

```bash
git clone [https://github.com/Leoces95/curso-analisis-algoritmos.git](https://github.com/Leoces95/curso-analisis-algoritmos.git)
cd curso-analisis-algoritmos```
