# Laboratorio 02 — Configuración del entorno de trabajo

Instrucciones para configurar y reproducir el entorno virtual de trabajo de la Semana 02:

1. **Creación del entorno virtual:**
python -m venv venv

2. **Activación del entorno virtual:**
- Git Bash en Windows: `source venv/Scripts/activate`
- Linux / macOS: `source venv/bin/activate`

3. **Instalación de dependencias reproducibles:**

pip install -r requirements.txt
